# FixOn Frontend

UniFix is a React web interface for exploring system dashboards, AI-assisted workflows, reusable blueprints, script repositories, dependency audits, and user settings.

This repository contains the frontend application only. It is built with React, Vite, Tailwind CSS, and React Router.

## Run locally

From the repository root:

```sh
npm run dev
```

Vite prints a local address (usually `http://localhost:5173`). To create a production build:

```sh
npm run build
```

The pages can be reviewed without launching a backend. Features that depend on authentication, live system data, or remote API services require those services to be available.
